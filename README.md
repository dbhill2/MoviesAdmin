# Movie Administrator Web App

This backend web app will be primarily used for records management of movies.\n
Captured in this backend C\# .NET app will be Admin/Critic login credentials, data for each movie object, and a place critic's to leave their reviews.\n
This app is function over form acting as a backend. Later on a public facing React app will be available for the consumers of this web app.\n

At this stage the fundamentals of CRUD will be implemented for proper showcasing of data.\n
